# Protocols — markdown staging

Markdown drafts of all lab protocols, source-of-truth for porting to Benchling. Each protocol is sourced **strictly** from `lab_notebook/digitalized/*.md` and the existing `protocol/*.docx|pdf` references — no invented procedures.

**Two exceptions to the "strictly from our own notebook" rule.**

1. **Added 2026-09-21:** [#26 Depolymerase Activity Assay](workflows/depolymerase_activity_assay.md) is transcribed from a **published paper**, at the PI's instruction, because the team has no prior experience with it. It carries a provenance banner saying so, and every value that is ours rather than the paper's is labelled inline.
2. **Added 2026-10-20 — #28–#32, the autumn protein track.** These five are transcribed from **printed bench documents** (plus one PDF) photographed on 2026-10-20, not from the notebook and not from a paper. They are the documents that were physically on the bench through September and October, and several carry **handwritten amendments** that contradict the printed text. Every one of them carries a provenance banner, every handwritten change is reproduced **separately from the printed text**, and the as-run notebook values are kept **beside** the printed ones rather than merged into them. **Three of the five are incomplete** — see the page-gap callouts in each file.

**Authoring rules:** [`_TEMPLATE.md`](_TEMPLATE.md) defines required sections, the `## Checklist` storage block, and the quick-lookup table format. When sources disagree on a value (team's as-run vs prof's vs kit default), **preserve all versions side-by-side** rather than picking one.
