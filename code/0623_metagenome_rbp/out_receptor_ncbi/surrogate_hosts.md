# Surrogate phage-host candidates

**Caveats:** receptor sequence identity is a WEAK proxy for phage host range (phages read variable surface loops, not whole-protein identity); NCBI shows the host carries the lock, not that its phage uses that lock. Leads to test, not answers. DB = 395 NCBI reference proteomes only.
