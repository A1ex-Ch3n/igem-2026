Project title: Phagenomics, 
**\*will be able to change later**

Project description: Bacteriophages kill bacteria by latching onto them with receptor-binding proteins (RBPs), the tail fibers that recognize specific molecules on a bacterium's surface. It's one of the most precise targeting systems in nature, but we still can't really program it. To match a phage to a given bacterium, you usually have to go through a long and uncertain hunt for one that happens to bind. Imagine instead a system where we can read a bacterium's genome, work out which receptors sit on its surface, and then engineer phage RBPs to bind them, all through computer simulated interactions and machine learning. We're Phagenomics, building the pipeline to construct phage RBPs against Pseudomonas on demand, and turning host range into something we can design instead of something we search for, with uses across agriculture, therapeutics, and beyond.
