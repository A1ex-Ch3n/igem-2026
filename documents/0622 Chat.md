## Dry Lab

Based on the existing bacteria genome:
1. BLAST them and find their specific phage on NCBI (local)
2. Find RBPs from these literature backed phages, create a fasta for each bacteria strain, and create a lookup table for it (local)
3. See if metagenomes contain any of the sequence (on Laguna)
4. Create a list from these recorded metagenomes
