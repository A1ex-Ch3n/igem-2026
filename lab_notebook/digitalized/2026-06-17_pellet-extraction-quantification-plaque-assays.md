### ② Plaque assays — see [[plaque_assay_layered_plate]]
- Prepared **150 mL 0.7 % LB agar**, autoclaved.
- Made a **fresh culture for every bacteria culture**: **5 mL LB broth + 50 µL bacteria**.
- **Per plate:** **3 mL 0.7 % LB agar + 300 µL bacteria** + phage —
  **200 µL extracted phage** *or* **150 µL phage filtrate**.

| Host + phage | Plates | Phage source |
|---|---|---|
| `9-9-2` Φ8, `9-6-2` Φ8, `9-2-1` Φ8 | 1 + 3 each (**3 × 4 = 12**) | 1 plate extracted phage, 3 plates filtrate |
| `9-10-1` Φ8, `9-10-1` Φ10, `9-1-2` Φ8, `6-8-2` Φ9, `6-10-2` Φ9 | 1 each (**5**) | extracted phage only |
| `6-6-2`, `6-7-2`, `8-7-1`, `6-2-2`, `6-6-1`, `10-9-1`, `10-10-1`, `10-7-2` | 3 each (**8 × 3 = 24**) | Φ3, Φ5, Φ6 (one plate per phage) |

**Total: 3 × 4 + 5 + 8 × 3 = 41 plates.**
